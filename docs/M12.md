# M12 family-held-out evaluation

M12 implements issue #23 without adding an architecture or M13 features. It reuses
M4 transferable sequence features and assay-local rank targets, M1/M5 frozen ESM-2
mutation-site features, M2 residue graphs, and the M5 structural-GNN/weighted-fusion/
bidirectional-attention models. Every supervised model is fit from scratch for each
fold. Historical checkpoints are deliberately not reused across family roles.

## Bounded scope and contracts

`configs/m12.json` pins eight ProteinGym v1.3 Tsuboyama domains, four Pfam families,
source hashes, experimental structures (seven NMR and one X-ray), graph settings, ESM revision, seeds and
model budgets. RCSB polymer-entity Pfam features (version 34.0) supply externally
assigned family identifiers and domain spans. UniProt whole-protein annotations are
not treated as assay-domain classifications. `validation.json` crosswalks the assay
reference positions onto the deposited entity's Pfam spans and retains SIFTS mappings.

This is a domain **stability mutation-effect** benchmark. The original source phenotype
is `ddG_ML_float`, with ProteinGym directionality +1. We preserve each assay's processed
`DMS_score` and report Spearman against it. M12 does not interpret a shared prediction
as calibrated thermodynamic ΔΔG or a common functional measurement. Per-assay midranks
are fitted on training observations only; scalers are fitted on training features only.
Assays with no training data receive no test-fitted target transformation.

Genotypes are sampled by salted sequence SHA256 without looking at outcome magnitudes.
Each protein contributes 96 measured variants, retaining single and double mutations.
The source's complete sequence is regenerated from the independently pinned reference
and checked against every mutation token. Missing labels are counted; nonfinite or
duplicate observations and mutation/reference discrepancies fail validation.

G1 retains 64/16/16 train/validation/test genotypes per protein. G2 uses eight complete
protein-held-out folds with known training families. Validation is a different protein
from the next family, whose partner remains in training. G3 uses four complete-family
folds: one family test, next family validation, other two train. Original genotype
partition tags remain in archived rows. G2/G3 necessarily override within-protein roles
with complete protein/family roles; they do not mix held-out protein variants into
training. No family or sequence cluster crosses G3 roles under the declared rules.

The global identity audit reports both-sequence coverage and ambiguous optima. Local
blocks independently screen domain/partial homologs. Global clustering at 40/60/80%
identity requires >=70% aligned coverage of both constructs. A local match >=25 residues,
>=50% identity and >=60% shorter-sequence coverage requires review if it crosses family
labels. Unresolved cross-family matches stop the runner. These are transparent screening
rules, not proof of no remote homology. In fact the annotated SH3 and homeodomain pairs
fall below 40% global identity, illustrating why a single identity cutoff is inadequate.
Nearest-training-neighbor audits retain local and global evidence for every held-out
protein. Frozen ESM pretraining family exposure is unknown.

## Structural mapping

All 768 selected genotypes have complete compatible mutation sites: sequence-all and
structure-matched cohorts coincide here, but are explicitly separate in the interface
and artifacts. The boolean structural mask and exclusions remain explicit; partially
mapped variants cannot enter structural models or their matched sequence comparisons.

PITX2 author chain is P. SAV1 has a repeated cloning tag that produces multiple optimal
unconstrained global alignments. The declared **1-based inclusive** polymer range 7–49
must equal the complete assay reference exactly. This opt-in M2 mapping parameter does
not change other callers. Bounds and reference content are checked; invalid ranges
fail. The full deposited model remains available for solvent accessibility, including
construct context, and graph nodes use only compatible assay-reference positions.

All eight graphs have one connected component, 100% reference identity and coordinate
coverage. Seven structures are solution NMR; BBC1/1TG0 is X-ray (0.97 Å). Structures use deposited model 0; this ignores NMR ensemble variability. See the archived ERRATA.md for the BBC1 display-name correction.
All B columns are conservatively masked in this fixed experiment and are not treated as pLDDT,
experimental crystallographic uncertainty or predictive uncertainty. Missing B-factor/
pLDDT descriptors use existing explicit masks. No mutant rearrangements are modeled.

## Selection and inference

Transferable sequence ridge: 67 composition, residue-substitution/property, count and
relative-position features (there is no meaningful common aligned one-hot coordinate
system across these families). ESM site ridge: 961 frozen mutant/delta/count features.
Structural ridge: 270 mutation-centered descriptors. Neural models: 16-wide, two graph
message-passing layers, heads=2, 12 epochs maximum, patience=4, three fixed seeds.
Architectural capacities differ and parameter counts are reported; weighted fusion is
a simpler architectural comparison, not an exactly capacity-matched attention control.
Ridge alpha uses [0.1,10,100]; only validation Spearman selects alpha/epoch. The balanced
validation design makes existing equal-protein macro selection equal-family macro.

No checkpoint is supervised on held-out proteins/families before fitting. Frozen
label-free ESM tokens and test-reference coordinates are permitted inference inputs.
The model sees held-out labels only when the selected fit's predictions are scored.
Offline neural tests alter all held-out labels and require bitwise-identical selected
states and predictions across the structural GNN, fusion and attention models.

Metrics average each protein's native-label Spearman equally within its family, then
average families equally. No pooled RMSE, mutation-level CI or significance is reported.
Four families are the effective replication units; seed SD is optimization sensitivity.
The primary table uses all original role test variants. A labeled secondary diagnostic
restricts already-saved predictions to common G1 test IDs across all protocols, avoiding
a refit or any new selection. Training size/diversity still differ between protocols.

## Exact reproduction

From the repository root, using Python 3.12 and the pinned existing dependencies:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-m3.txt
.venv/bin/python -m pip install -e '.[dev,m3,m1]'
.venv/bin/python -m proteinmod.family_experiments --acquire
```

If the pinned frozen ESM weights are not cached, acquire them explicitly once:

```sh
.venv/bin/python -c 'import json; from proteinmod.embeddings import FrozenESM; FrozenESM(json.load(open("configs/m12.json"))["embedding"], local_only=False)'
```

Then prepare label-free features and run the complete fixed experiment:

```sh
.venv/bin/python -m proteinmod.family_experiments --prepare
.venv/bin/python -m proteinmod.family_experiments
.venv/bin/python scripts/verify_m12.py
.venv/bin/ruff check .
.venv/bin/ruff format --check .
.venv/bin/pytest -q
```

Experiment outputs go to ignored `runs/m12/`; archived evidence is `benchmarks/m12/`.
`verify_m12.py` checks the archived evidence by default and requires acquired raw sources,
graphs, frozen feature manifests and local checkpoint files. To verify a fresh run,
copy the unchanged archived `preregistration.json` and `PREREGISTRATION.md` into
`runs/m12/`, then pass `--directory runs/m12`. Do not overwrite historical benchmarks.
Training-only CPU checks do not require the ESM weights or a network connection.

The first preregistration Git commit is `f1f8c24`; the config and plan hashes are
recorded in `benchmarks/m12/preregistration.json`. `--acquire` fetches only eight selected
ZIP members and eight small structures/annotation records. No full ProteinGym download
is required. ESM runs on MPS where available; neural fits use deterministic CPU operators
for repeatable graph aggregation. Float/software versions can affect cross-platform
results; environment.json records the actual local versions, device, time and memory.

## Limits

Four families with two proteins each support a bounded family-held-out test, not a broad
claim of universal cross-family generalization. They are small selected domains from one
study, with family/construct confounding and uneven single/double mutation fractions.
Assay methodology is shared but constructs and outcomes need not share scales. G3 trains
on only four proteins from two families, and 12 epochs is a fixed speed budget, not a
model performance ceiling. ESM-2/structural pretraining exposure cannot be removed.
Generalization gaps cannot isolate evolutionary distance from training diversity or size.
Remote homologs below the screening criteria may remain. More independent families and
functional endpoints are needed for wider claims. Negative results are retained.

Actual local numerical replay is available with:

```sh
.venv/bin/python scripts/replay_m12.py
```

This retrains seed 0 for the first G3 fold in all three neural architectures, requiring
bitwise-identical held-out predictions, validation traces and selection diagnostics.
It writes `benchmarks/m12/replay.json`; it does not replace any historical milestone.
