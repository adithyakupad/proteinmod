# M22.1: synthetic fixed-horizon regression diagnostic

Registered before any synthetic trajectory is run. Exact settings: [m221_synthetic.json](../../configs/m221_synthetic.json). This is an artificial software/optimization diagnostic, not protein modeling or validation of a historical scientific hypothesis. All M0–M21 evidence and external holdouts remain untouched.

One fixed trainable 16 → 64 tanh → 1 MLP, Glorot weights and zero biases, float64 MSE regression. Adam lr .003, betas .9/.999, epsilon 1e-8, batch32. No weight decay, clipping, scheduler, early stopping, normalization of targets, architecture alternatives or hyperparameter search. Only feature means/population SDs fitted on training arrays. Independent normal inputs; target sin(x0)+.5*x1 plus independent normal noise.

Two scenarios are fixed: ample_clean (512 training, noise SD .05) and scarce_noisy (32 training, noise SD 3). Each has 256 validation and 2048 test rows. Both train and evaluation labels use the same noise distribution within a scenario; no deliberate distribution shift. Seeds0–9 independently regenerate data, initialization and minibatch order through separate PCG64 namespaces. The initialization namespace is shared between scenarios at the same seed; scenario comparisons are not causal isolation of sample size versus noise.

For each seed/scenario, run one 120-epoch trajectory, retain fixed epochs12 and120, and never use validation/test metrics in optimization or checkpoint selection. Both epochs share the same data, scaler, initial state and first12 epochs. No best-epoch selection. Training loss must be evaluated at the frozen state on the complete training set, not estimated from online minibatches.

Primary: test MSE120 − MSE12 separately per scenario. Negative favors longer training. Also report train/validation MSE and all three split Spearman correlations, using average ranks for ties and null for undefined correlations. Positive rank delta favors longer training. Report every seed, scenario, endpoint and paired effect. No protein data, phenotype acquisition, variant generation or predictive model is used for biological purposes.

Expected scenario claims require the proposed MSE direction in at least8/10 seeds and the nominal95% paired Student-t interval excluding zero. The overfitting scenario also requires negative mean train-MSE change. Expectations may fail; retain the fixed scenarios and report the failure without tuning. Rank directions are secondary and need not match MSE. Intervals describe variability over this synthetic generator, initialization and ordering, not just initialization or uncertainty over proteins. Report SD, SE and df9 t intervals; two scenario intervals are nominal and not simultaneous. No population significance or biological conclusion.

Verification: finite-difference gradient check on tiny artificial arrays; exact full rerun; epoch12 parameter/Adam/RNG resume through120; separate12-epoch prefix equivalence; recompute checkpoint metrics and paired effects; adversarial held-out inputs/labels leave scaler and training states bitwise unchanged. Synthetic test outcomes are used only for this once-declared diagnostic; no new scenario is selected from their behavior.

Binary checkpoint arrays may be written only to the dedicated ignored run directory. Commit aggregate JSON metrics and state digests, not input arrays or weights. The runner must refuse an existing output directory. Record environment, precise protocol/implementation hashes and any failures. Cross-platform tolerance is distinct from bitwise same-environment replay; no universal bitwise portability claim.
