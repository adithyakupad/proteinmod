# M18 prospective admission protocol — no target-label access

Baseline main 73f0666a87560dadffa76f34f5255856d2ce7459. Preserve all M0–M17 bytes,
negative results and original preregistration. No new architecture, merge or tag.

The M17 H1–H5 hypotheses, direction criteria (0.02 rho; >=3/4 development-family
agreement), five seeds 0–4, fractions 10/25/50/100%, ridge alphas [0.1,10,100],
12-epoch/patience4 graph budgets and physical/degree-null controls remain frozen.
External evidence is a prospective test of those fixed interventions, not another
opportunity to select an intervention using its test score. With only two new
families possible, report both paired family effects and no stable population CI;
the original >=3/4 criterion cannot be claimed satisfied by two external families.

Admission requires individual table/column => primary experimental assay => methods
and deposition linkage, not publication or archive attribution. Code cells may be
inspected without notebook outputs; GEO metadata and table headers are allowed.
Download bytes may be hashed/quarantined but phenotype columns must not be inspected,
parsed numerically, used for filtering or fitted until exact admission and roles
are committed. Missing/censored labels cause predeclared common exclusions, never
replacement by favorable examples. No provenance gate is selected by performance.

Candidate: primary GEO GSE266299 sparse_DTS_core_mutagenesis, yeast abundancePCA.
This is intracellular abundance/growth proxy, NOT folding ΔΔG. Primary author code
separately imports the new replicate table and Tsuboyama comparison tables. Resolve
sample IDs, WT/reference mutations, score and uncertainty semantics, censoring,
conditions, license and exact file identity. FLIP's target transform remains a
separate unresolved edge unless direct processing evidence establishes it; do not
silently call the primary table the same as FLIP. Reject FYN from unseen-family
claims because SH3 was development data. Require independent Pfam evidence for
CI-2A and CspA, verified physical graphs and explicit similarity audits against
all previously supervised references. Freeze up to96 variants/accepted protein
by SHA256('m18:external:'+protein+sequence), ignoring score values. No external
training, validation or calibration labels: accepted external families are TEST only.
Do not infer WT from sample consensus. Use author-published construct sequences.

If accepted, retain four rotations of development-family source roles: two source
families train using original 64 train rows/protein, next family validates using
original16 validation rows/protein, remaining source family calibrates using its
original16 validation rows/protein. External selected variants are test only for
every model, fraction, seed and rotation. No supervised external examples, no test
residual calibration, no changing this source role assignment after labels. Freeze
actual IDs, graph masks, file hashes, family ontology and exact model configs in
Phase B before target access. Generate and hash predictions BEFORE target unblinding.

Existing models only: structural ridge, scaled/unscaled frozen ESM mutation-site
ridge, original GNN, edge GNN, degree-preserving graph-null. No new fusion reference.
Ridges run all four fractions; graphs at25/100% as M17. All eligible test variants
must be matched across all methods; report common mapping exclusions. Frozen
encoder pretraining exposure remains unknown; independent measurement/family
separation is not a claim of pretraining independence.

H1: paired low-label effects. H2: source M17 matched familiarity results retained
as development context; external transfer jointly shifts family/assay/burden and
cannot isolate familiarity. H3/H4: physical vs same-capacity degree null, atom/contact
checks; no new matched control invented after outcomes. H5: fixed scaled vs unscaled
ESM comparison. Primary per-protein Spearman and equal-family macro, paired effects;
undefined rho retained. No pooled cross-assay RMSE. Uncertainty/calibration only
where units/target semantics justify it; no native kcal/mol for abundance scores,
no guaranteed conformal coverage under family/assay shift. Calibration role is
explicit but may be declared ineligible for cross-assay intervals rather than invent
paired labels. Keep primary labels blinded if any mandatory admission edge fails.
