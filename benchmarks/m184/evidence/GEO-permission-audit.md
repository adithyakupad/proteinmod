# GEO item permission and licensed-deposit lineage

2026-10-19. Authoritative terms retrieved as primary indexed page text through
web search; direct requests had previously returned an anti-bot page. This
record is a paraphrased evidence note, not a claimed byte-identical HTTP archive.

The complete [GEO disclaimer](https://www.ncbi.nlm.nih.gov/geo/info/disclaimer.html)
states that NCBI itself imposes no use/distribution restrictions, while reserving
possible submitter intellectual-property rights that it cannot adjudicate or
license. Its copyright section permits download/reproduction unless otherwise
stated, but requires compliance with retained author/publisher rights. The
[GEO FAQ](https://www.ncbi.nlm.nih.gov/geo/info/faq.html) confirms public download
without login and refers users to that disclaimer. This supports access; it is
not evidence that this experiment is legally prohibited. It also does not supply
the file-specific grant required by our unchanged admission protocol.

The author README concept DOI11175469 now resolves to **16266645**, version2025
(CC-BY-4.0), rather than old11175470. Archived API metadata and both complete ZIP
central directories establish93 code entries and3682 data entries. We retrieved
only the README member (CRC checked) and processed-table header (whole member CRC
not checked). Whole19.7MB/2.23GB archive MD5s are publisher-declared, not verified
full downloads. Range-directory transfer counts are recorded separately.

`zenodo/Fig2/Sparse_DTS_Cores_fitness_replicates.txt` has19073162 uncompressed
bytes and CRC1319611062, matching the prior licensed Fig1 table inventory.
Its header includes replicate `fitness1_uncorr`, `fitness2_uncorr`, `fitness`,
`sigma`, `growthrate` and related fields, but does not name GEO's `fitness_raw`
and `sigma_raw`. Header differences are not proof of unrelated measurements.
No outcome row was decoded and no numerical equality was tested.

The licensed author README identifies Zenodo as the processed-data source and
GEO as the raw FASTQ source; it does not expressly extend CC-BY to this separate
GEO processed-score CSV. The published Fig2/FigS1 source-only projections already
archived under `data/cache/m18/source/` read the processed replicate table and
identify the proteins by sequence. No export to this GEO CSV or documented
raw-column transformation is established in those inspected projections. The
current author GitHub head remains f978897ef3a278796acc0e87e5cd82d4d0d10082;
its recursive filename inventory has no standalone license/export manifest.
This is a bounded lineage audit, not a claim to have proven that no mapping can
exist in any notebook or unpublished processing script. Notebook outputs and
phenotype figures were never inspected.

Consequently **PARTIAL** remains the file-specific permission gate for CspA and
CI2. A specific author grant, or an authoritative derivation/license statement
covering the exact raw columns, can resolve it without opening outcomes.
Download, internal analysis, aggregate publication, predictions/weights sharing,
raw redistribution and commercial rights are separate questions in the
[unsent request](../PERMISSION_REQUEST.md). No correspondence was sent.
