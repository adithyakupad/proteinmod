## What the primary methods resolve

The assay measures abundance-associated growth in yeast. Two biological replicates
were used for the pooled sparse-core selection. DiMSum 1.3 computes a natural-log
ratio of output/input read enrichment relative to a reference. Thus greater
fitness denotes greater relative enrichment; it is not kcal/mol.

Published production restrictions include library membership, minimum base Q20,
and input support in all replicates. The deposited command fixes
`fitnessMinInputCountAll=30`; this is an input-count rule, not an observed-fitness
cutoff inferred by this audit. The command points at explicit library/synonym
identity maps. Those maps' data values were not inspected.

The methods distinguish these measurements from later plotting normalization
using a distribution mode and a selected reference. The notebook source consumes
the processed table and then performs this normalization. We did not compute its
anchors, inspect distributions, adopt source reference flags, or run it.

These observations support the biological meaning and rank direction of a
prospective author-column endpoint. They do **not** prove that the deposited
`fitness` is numerically identical to GEO `fitness_raw`, or establish all operations
between DiMSum output and this exact table. In particular, the bounded source pass
found consumers but no exact export/replicate-combination producer. Additional
export filtering, censoring and missingness remain unresolved. Unknown is not
asserted to mean absent, nor assumed to mean outcome-dependent filtering occurred.

The blocker is **selection/target lineage**, not a demand for exact normalization
bytes or log-unit comparability. Affine rescaling can preserve ranks, but does not
resolve undocumented variant selection, censoring or an untraced export.
